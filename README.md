# Medicate – AI-Powered Healthcare Aggregator

## Overview
Medicate is a full-stack healthcare platform that aggregates multiple healthcare services in one place. It provides basic AI-assisted triage, a chatbot for health guidance, appointment booking, and a pharmacy locator to help users find nearby medical stores.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: MongoDB
- AI Integration: Google Generative AI
- Deployment: Render

## Features
- User authentication and session management
- AI-based health guidance and chatbot
- Appointment booking module
- Pharmacy locator
- REST APIs for healthcare services

## Project Structure
- /app.py – Flask application entry point
- /templates – Frontend templates
- /static – CSS/JS files
- /routes – API routes 

## Live Demo
- Application:https://medicate-healthcare-platform.onrender.com

## Known Limitations
- Basic UI and validations (learning project)
- AI responses depend on third-party API limits
- Not production-grade healthcare advice
